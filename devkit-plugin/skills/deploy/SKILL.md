# deploy — 안전한 출시

## 환경 단계

| 단계 | 풀어 쓴 이름 | 게이트 |
|---|---|---|
| sandbox | 내 작업방 | 없음 |
| team | 팀 공용 | 자동 점검 + 도구 자가 리뷰 |
| prod | 실서비스 | 보안 점검 + 누가 한 명 리뷰 |
| external | 외부에 열기 | 보안팀 자동 알림 + 컴플라이언스 점검 |

## 흐름

1. 현재 환경 추정(브랜치/사용자 의도). 모호하면 `clarify`로 *"내 작업방 / 팀 / 실서비스 / 외부"* 묻는다.
2. **연결·설정 점검** — 환경에 맞는 연결(`connections`)이 모두 설정돼 있나? 시크릿이 평문으로 저장돼 있지 않나?
3. **시뮬레이션 먼저** — Bicep `what-if` 또는 같은 효과의 사전 점검을 돌리고, 영향받는 곳을 트리로 표시.
4. 사용자 동의를 받은 후에만 실제 적용.
5. **출시 직후 5분간** *"되돌리기"* 버튼 항상 표시. 5분 후엔 메뉴로.
6. **자동 알림** — 외부 노출인 경우 보안팀에 자동 알림(사용자 확인 후 전송).

## 사용자 화면 용어 정책

`${CLAUDE_PLUGIN_ROOT}/references/glossary.md`. *Bicep / what-if / managed identity / Key Vault* 같은 단어 노출 금지. *시뮬레이션 / 안전한 접속 정보 / 비밀창고* 정도.

## 출력 메시지 (사용자에게 보여줄 말)

```
🚀 출시 전 점검

대상: <"팀 공용" / "실서비스" 등 풀어 쓴 이름>
바뀌는 곳: <영향 항목 N개 — "주문 화면 1, 표 2, 자동화 1">
연결: 모두 설정 완료 ✅ (또는 ⚠️ 빠진 곳 안내)
비밀번호/토큰: 안전한 비밀창고에 보관 중 ✅

시뮬레이션 결과:
  ① <"주문 화면이 새로 추가됩니다">
  ② <"재고 표가 갱신됩니다">

진행할까요?  [네 / 아뇨 / 시뮬레이션 다시]
```

출시 후:
```
✅ 출시했어요. 5분 안에 *"되돌리기"* 누르면 즉시 원상복구돼요.
```
