# catalog-hint — 비슷한 사례 추천

## 흐름

1. 의도 키워드(예: *"주문 / 승인 / 알림 / 별점"*)를 1~3개 추출.
2. `references/templates/index.yaml`을 읽어 태그/요약/안 좋은 케이스를 매칭.
3. 일치도 높은 1~3개를 추천 카드로 표시. *"여기서 시작할까요? / 빈 화면에서 시작할까요?"* 선택.
4. 사용자 선택은 학습 신호 — 텔레메트리에 남겨 다음 추천에 반영.

## 사용자 화면 용어 정책

`${CLAUDE_PLUGIN_ROOT}/references/glossary.md`. *템플릿 / 카탈로그 / 인덱스 / 태그* 같은 단어는 *예시 / 모음 / 분류* 정도로 풀어 쓴다.

## 출력 메시지 (사용자에게 보여줄 말)

```
🗂️ 비슷한 사례 N개:

① 주문/재고 기본형 — 인사팀이 작년에 만들어둔 거예요. 표 4개 + 화면 5개 포함.
② 알림 자동화 묶음 — 마케팅팀에서 자주 쓰는 형식. 트리거-액션 카드 한 장.

여기서 시작할까요?  [① / ② / 빈 화면에서 시작]
```
