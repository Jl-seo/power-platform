# FlowOps 포털 — UI/UX 설계 및 메뉴체계도

> 설계 원칙: **"한 화면에서 상태 파악, 두 클릭 안에 조치"**
> 페르소나별 첫 화면이 다름 — PM은 일정, 개발자는 내 과제, 운영자는 실행 현황, 관리자는 거버넌스.

---

## 1. 페르소나와 핵심 여정

| 페르소나 | 가장 자주 하는 일 | 첫 화면 (기본 랜딩) |
|---|---|---|
| **PM/영업** | 프로젝트 진척 확인, 고객 보고 | 홈 대시보드 (진척 요약) |
| **개발자** | 내 과제 확인, 배포 요청, 준수검사 결과 | 내 작업 |
| **운영자** | 오늘 실행 현황, 오류 처리 | 운영 모니터링 |
| **관리자(거버넌스)** | 테넌트 인벤토리, 정책, 준수율 | 거버넌스 |

## 2. 메뉴체계도 (IA)

```
FlowOps 포털
│
├─ 🏠 홈 대시보드
│    ├─ KPI 카드: 진행 과제 / 오늘 실행 성공률 / 지연 과제 / 준수율
│    ├─ 프로젝트별 진척 차트
│    ├─ 최근 배포 / 최근 오류 피드
│    └─ 내 알림 (승인 대기, 위반 알림)
│
├─ 📋 프로젝트 관리
│    ├─ 프로젝트 목록          (프로젝트코드/고객사/PM/기간/진척률)
│    ├─ 과제 대장              (과제코드 채번 · 단계 자동 전환 표시)
│    ├─ 일정 보드              (칸반: 착수전→개발중→테스트→운영  |  간트 뷰 전환)
│    └─ 산출물함               (자동 생성 문서: 흐름정의서/테스트결과/배포이력 + 수동 업로드)
│
├─ 🛠 개발
│    ├─ 내 작업                (담당 과제 + 준수검사 결과 + 조치 필요 항목)
│    ├─ 템플릿·라이브러리 카탈로그 (템플릿 v2 다운로드, 공통 라이브러리 버전/문서)
│    ├─ 개발 가이드            (명명규칙, 체크리스트, 표준 문서 뷰어)
│    └─ 준수 검사              (과제별 검사 결과 · 위반 상세 · 재검사 요청)
│
├─ 🚀 릴리스
│    ├─ 배포 요청              (파이프라인 실행 링크 + 사전 체크리스트)
│    ├─ 승인함                 (내가 승인할 배포 — Teams 연동)
│    ├─ 배포 이력              (환경별 타임라인 · 버전 비교)
│    └─ 코드 저장소            (버전별 솔루션 아카이브 · 다운로드 · 복원 요청)
│
├─ 📡 운영 모니터링
│    ├─ 실행 현황              (실시간: 실행중/성공/실패/미실행 — Heartbeat 경고)
│    ├─ 오류 대장              (S/B/D 분류 · 처리상태 관리 · 담당자 배정)
│    ├─ SLA 리포트             (과제별 실행시간 추이 · SLA 위반 이력)
│    └─ 머신/실행계정 현황     (데스크톱 흐름 머신 상태)
│
└─ 🛡 거버넌스 (관리자 전용)
     ├─ 테넌트 인벤토리        (Inventory API — 앱/흐름/에이전트 전체, 미등록 리소스 검출)
     ├─ 환경 관리              (환경 목록 · 그룹 · 개인 dev 환경 신청/승인)
     ├─ DLP·정책               (커넥터 정책 현황 · 위반 알림 이력)
     ├─ 준수율 리포트          (조직/프로젝트/개인별 준수율 추이)
     └─ 플랫폼 설정            (채번 규칙 · SLA 기본값 · 알림 수신자 · 검사 규칙)
```

## 3. 핵심 화면 설계 (와이어프레임 수준)

### 3.1 홈 대시보드 — "어필의 핵심 화면"

```
┌────────────────────────────────────────────────────────────────┐
│ [진행 과제 24]  [오늘 실행 성공률 96%]  [지연 과제 2]  [준수율 91%] │  ← KPI 카드 4개
├──────────────────────────────┬─────────────────────────────────┤
│ 프로젝트별 진척 (가로 막대)     │ 오늘 실행 타임라인               │
│  A고객사 ███████░░ 72%       │  09:00 ✅ [DKS-HR-001]          │
│  B고객사 █████████ 95%       │  09:30 ✅ [DKS-FI-003]          │
│  C고객사 ███░░░░░░ 31%       │  10:00 ❌ [DKS-SC-002] → 오류    │
├──────────────────────────────┼─────────────────────────────────┤
│ 최근 배포 (자동 기록)          │ 조치 필요                        │
│  [HR-001] v1.2 → PROD ✅     │  ⚠ 승인 대기 1건                 │
│  [FI-003] v2.0 → TEST ✅     │  ⚠ 준수 위반 3건                 │
│                              │  🔴 Heartbeat 누락 1건           │
└──────────────────────────────┴─────────────────────────────────┘
```

**포인트**: 이 화면의 모든 숫자가 **수동 입력 0** — 배포/실행/검사가 자동으로 만든 데이터.

### 3.2 과제 대장 — 단계 자동 전환 시각화

```
과제코드     과제명          담당    단계           계획     실적     상태
DKS-HR-001  입사자온보딩     김개발  ●●●●○ 운영     05-01   05-01✔  정상
DKS-FI-003  전표자동기표     이개발  ●●●○○ 테스트   05-10   -       진행
DKS-SC-002  재고일일마감     박개발  ●●○○○ 개발중   05-15   -       ⚠지연
```
- 단계 점(●)에 마우스 오버 → "TEST 배포 2026-05-02 14:30 (Pipelines 자동 기록)" 툴팁
- **실적일을 사람이 입력하지 않는다** — 이게 데모 포인트

### 3.3 산출물함 — 자동 생성 강조

```
[DKS-HR-001] 입사자온보딩
  📄 흐름정의서_v1.2.docx      🤖자동생성  2026-05-01   ← 솔루션 메타데이터에서
  📄 테스트결과서_v1.2.xlsx    🤖자동생성  2026-04-28   ← 실행이력에서
  📄 배포이력서.pdf            🤖자동생성  2026-05-01   ← Pipelines 기록에서
  📄 과제정의서_v1.0.pptx      ✋수동      2026-04-01
```
- 🤖 뱃지가 자동 생성 산출물 — 산출물의 70%가 이 뱃지를 달게 하는 것이 목표

### 3.4 코드 저장소

```
[DKS-HR-001] 버전 이력
  v1.2  2026-05-01  PROD 배포  솔루션.zip (2.1MB)  [다운로드] [이 버전으로 복원 요청]
  v1.1  2026-04-20  TEST 배포  솔루션.zip (2.0MB)  [다운로드]
  v1.0  2026-04-10  TEST 배포  솔루션.zip (1.8MB)  [다운로드]
```

## 4. 구현 기술 선택

| 후보 | 장점 | 단점 | 판정 |
|---|---|---|---|
| **모델 기반 앱** | Dataverse 네이티브, 보안 역할 연동, 빠른 구축 | 디자인 자유도 낮음 — "수려함" 한계 | 관리자 백오피스용 |
| **캔버스 앱** | 디자인 자유, 한국어 UI 완전 제어 | 복잡 화면 성능, 반응형 수작업 | 후보 |
| **코드 앱 (React)** | **디자인 완전 자유 + 수려한 대시보드 가능**, Dataverse SDK 내장 | pac CLI 개발 환경 필요 | **포털 프론트 권장** |
| Power BI (임베드) | 차트 품질 최고 | 조치(쓰기) 불가 | 대시보드 차트만 임베드 |

**권장 조합**: 코드 앱(React) 포털 + Power BI 임베드 차트 + 모델 기반 앱(관리자 설정) — 전부 Power Platform 안, 별도 인프라 0.

## 5. 디자인 시스템 (초안)

- **컬러**: 기본 남색(#1B2A4A) + 포인트 청록(#0FA3A3) / 상태색: 성공 #107C10, 실패 #D13438, 경고 #F7A800, 지연 #FF8C00
- **타이포**: Pretendard (한국어 최적화)
- **레이아웃**: 좌측 고정 사이드바(240px, 아이콘+라벨) + 상단 글로벌 바(검색·알림·프로필)
- **상태 표현 원칙**: 색+아이콘+텍스트 3중 표기 (색약 대응)
- **테이블 원칙**: 모든 목록에 상태 필터 칩, 열 정렬, Excel 내보내기
- **알림 원칙**: 포털 알림센터 + Teams 카드 이중화 — 조치 링크 포함 (딥링크)
